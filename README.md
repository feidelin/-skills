# 学术志 Skills 仓库

学术志联合创始人一平博士的公开 skills 仓库，涵盖学术科研各领域，包含论文选题、研究设计、研究方法、文献检索与核查、文献阅读、文献综述、资料分析、期刊论文写作、博士论文写作等。

## 安装方法

需先安装 [Claude Code](https://claude.ai/code)，然后在终端运行对应命令即可。

---

## Skills 列表

### 论文写作与审阅

| Skill | 功能 | 安装命令 |
|---|---|---|
| `feishu-paper-reviewer` | 在飞书云文档上直接进行论文审阅，支持高亮、删除线、划词批注 | `claude skill install https://github.com/yipng05-max/-skills/tree/main/feishu-paper-reviewer` |
| `paper-reviewer` | 对 Word/PDF 论文进行评阅，生成带标注的 Word 文档 | `claude skill install https://github.com/yipng05-max/-skills/tree/main/paper-reviewer` |
| `paper-analyzer` | 基于12个阅读要素对论文进行结构化拆解与分析 | `claude skill install https://github.com/yipng05-max/-skills/tree/main/paper-analyzer` |
| `paper-formatter` | 按目标期刊格式规范排版论文 | `claude skill install https://github.com/yipng05-max/-skills/tree/main/paper-formatter` |
