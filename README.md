# Academic Skills Repository

A public skills repository by Dr. Yiping, co-founder of AcademicZhi (学术志). Covers all stages of academic research, including topic selection, research design, methodology, literature search & verification, literature reading, literature review, data analysis, journal paper writing, and doctoral dissertation writing.

## Installation

Requires [Claude Code](https://claude.ai/code). Run the corresponding command in your terminal to install any skill.

---

## Skills List

### Paper Writing & Review

| Skill | Description | Install |
|---|---|---|
| `feishu-paper-reviewer` | Review academic papers directly in Feishu (Lark) cloud documents — supports highlighting, strikethrough, inline comments, and annotation | `claude skill install https://github.com/yipng05-max/-skills/tree/main/feishu-paper-reviewer` |
| `paper-reviewer` | Review Word/PDF papers and generate an annotated Word document with visual markup | `claude skill install https://github.com/yipng05-max/-skills/tree/main/paper-reviewer` |
| `paper-analyzer` | Structured paper analysis based on 12 reading elements | `claude skill install https://github.com/yipng05-max/-skills/tree/main/paper-analyzer` |
| `paper-formatter` | Format manuscripts to match a target journal's style | `claude skill install https://github.com/yipng05-max/-skills/tree/main/paper-formatter` |
