# 学术志 Skills 仓库

学术志联合创始人一平博士的公开 skills 仓库，涵盖学术科研各领域的 skills，包含论文选题、研究设计、研究方法、文献检索与文献核查、文献阅读、文献综述、资料收集、资料分析、期刊论文写作、博士论文写作、专著写作、畅销书写作等。

## 可用 Skills

### 飞书文档论文审阅 

直接在飞书云文档上进行学术论文审阅，支持高亮、删除线、加粗变色、划词批注、插入审阅意见等多种修订标记。

你想调用哪个 skill？请告诉我 skill 名称，例如 `/commit`、`/paper-reviewer` 等。

---

### Word/PDF 论文评阅 

对 Word（.docx）或 PDF 格式的学术论文进行专业评阅，生成带评阅标注的 Word 文档。支持可视化评阅（红色删除线、蓝色下划线、黄色底纹）和 Word 修订痕迹两种模式。

你想调用哪个技能？可以直接输入 `/技能名称`，例如 `/paper-reviewer` 或 `/cnki-advanced-search`。

如需查看所有可用技能，可以告诉我你想做什么，我来推荐合适的技能。
