# TA 研究全流程工作流

从文献检索到论文完稿的一站式流程协调器。本 skill 本身不做分析和写作工作——
它的职责是：按顺序调度各专项 skill，在每个阶段结束后呈现产出摘要，等待你确认后再继续。

**你在整个过程中只需要：选择选项、确认产出、提供材料。**

---

## 启动：一次性收集基本信息

> 欢迎启动 TA 研究全流程工作流。
>
> 在开始之前，请告诉我以下信息（后续所有环节共用，无需重复提供）：
>
> 1. **研究主题与研究问题**：你在研究什么？核心问题是什么？
> 2. **访谈材料**：访谈记录的文件路径，或稍后提供（可在编码阶段再上传）
> 3. **目标期刊类型**：C刊 / SSCI（影响写作规范与篇幅要求）
> 4. **已完成的工作**：以下哪些步骤你已经完成？（可跳过已完成的检查点）

>    - [ ] 文献综述写作
>    - [ ] 理论框架建构
>    - [ ] 主题分析编码
>    - [ ] 其他（请说明）

收到基本信息后，呈现完整工作流概览，让研究者知道接下来会发生什么：

## 检查点格式规范

每个检查点遵循统一格式：

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
检查点 N / 10：[检查点名称]
正在调用：[skill 名称]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

检查点完成后：
```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✅ 检查点 N 完成
产出：[文件名]（[字数/条目数]）
摘要：[2–3句话说明本阶段产出了什么]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
继续进入检查点 N+1？
> 输入"继续"进入下一步
> 输入"重做"重新执行本检查点
> 输入"跳过"跳过下一检查点
> 输入"暂停"保存进度，稍后继续
```

## 检查点 1：文献检索

**调用**：`cnki-advanced-search` + `foreign-literature-search`（双轨并行）

**操作**：
- **中文**：在知网高级检索中检索 CSSCI 来源期刊文献，按被引量排序
- **外文**：将关键词翻译为英文，通过 WebSearch 检索 SSCI 社会学核心期刊；同步生成 WoS/Scopus 布尔检索式

**用户确认**：
- 审阅中英文检索结果，确认纳入文献范围
- 可分别要求调整中文或外文检索词后重新检索

**产出**：
- `知网检索结果_{关键词}_{日期}.xlsx`（CSSCI 中文文献）
- `外文文献检索_{关键词}_{日期}.xlsx`（SSCI 外文文献 + WoS 检索式）

---

## 检查点 2：文献综述写作 + 引用核查

**调用**：`literature-review-writer` → `literature-verifier`

**操作**：
1. 基于检索到的文献，生成文献综述全文（含研究空白导出）
2. 自动调用 `literature-verifier` 核查所有引用的真实性
3. 呈现核查报告，标注存疑引用

**用户确认**：
- 审阅综述内容，确认研究空白的表述
- 处理存疑引用（删除/替换/保留并标注）

**产出**：`literature_review.md` + 引用核查报告

---

## 检查点 3：理论框架建构

**调用**：`ta-framework-builder`

**操作**：
- 确认理论定位（A理论驱动 / B经验驱动 / C敏感性概念）
- 逐步引导候选理论评估、理论选择与整合逻辑、核心概念操作化
- 生成理论框架文档

**关键确认**：理论定位（A/B/C）将贯穿后续所有检查点，请认真选择。

**用户确认**：
- 审阅理论选择论证
- 确认核心概念操作化定义

**产出**：`framework_[研究主题].md`

---

## 检查点 4：主题分析编码

**调用**：`thematic-analysis`

**操作**：
- 逐份访谈进行初始编码（自动保存每份编码结果）
- 每份访谈完成后暂停，供研究者审阅
- 所有访谈完成后进入主题识别、审查与命名阶段
- 呈现主题汇总表，供研究者确认主题命名

**注意**：本检查点可能跨多个对话轮次完成（多份访谈）。
每份访谈编码完成自动保存后，可随时暂停，下次从下一份访谈继续。

**用户确认**：
- 确认每份访谈的编码结果（可要求修改）
- 最终确认主题命名（命名权归研究者）

**产出**：`coding_[被访者].md`（每份访谈一个）+ 主题汇总表

---

## 检查点 5：研究方法章节写作

**调用**：`ta-methods-writer`

**操作**：
- 自动读取项目目录中所有 `coding_*.md` 文件，提取访谈份数、被访者信息、研究主题
- 读取 `framework_[主题].md`，提取理论定位（A/B/C）
- 仅就无法推断的信息向研究者提问（抽样标准、访谈时间、形式、时长、伦理等）
- 生成完整研究方法章节草稿，含：研究设计、研究对象与抽样、数据收集、数据分析、质量保障、研究伦理

**用户确认**：
- 审阅草稿，重点核查访谈对象描述和分析过程叙述是否与实际一致
- 修改后确认

**产出**：`methods.md`

---

## 检查点 6：引言写作

**调用**：`introduction-writer`

**操作**：
- 基于研究问题、研究背景、文献综述中的研究空白，生成引言章节全文
- 诊断研究问题性质（现象驱动/理论驱动/方法驱动），选择对应叙事策略
- 完成质量自检（无套话、研究空白自然导出、贡献具体）

**用户确认**：
- 审阅引言，确认研究空白的表述和贡献声明

**产出**：`introduction.md`

---

## 检查点 7：理论框架章节写作

**调用**：`ta-framework-writer`

**操作**：
- 导入检查点 3 生成的框架文档
- 根据理论定位（A/B/C）生成对应形态的章节文字：
  - A → 独立的理论框架章节（1500–2500字）
  - B → 方法章节中的理论取向简述（300–500字）
  - C → 方法章节中的理论取向说明（600–1000字）
- 完成质量自检（反标签检验、机制检验、引用核查）

**用户确认**：
- 审阅章节内容
- 确认章节在论文中的位置（根据 A/B/C 有所不同）

**产出**：`framework_section_[A/B/C].md`

---

## 检查点 8：研究发现写作

**调用**：`ta-findings-writer`

**操作**：
- 导入主题汇总表
- 确认叙事结构（并列型/串联型）
- 逐主题生成：主题阐释 → 引语证据 → 分析解释（→ 承接句）
- 完成整体检查（引语/分析比例、命名一致性、理论定位一致性）

**用户确认**：
- 审阅各主题的叙事段落
- 检查引语选取是否恰当，分析解释是否充分

**产出**：`findings.md`

---

## 检查点 9：讨论与结论写作

**调用**：`ta-discussion-writer`

**操作**：
- 导入发现章节 + 理论框架 + 文献综述要点
- 根据理论定位生成：
  - 跨主题综合
  - 理论对话（一致/差异/推进）
  - 理论贡献（三重检验）
  - 研究局限
  - 未来研究方向
  - 结论
- 完成质量自检

**用户确认**：
- 重点审阅理论对话和贡献声明
- 确认局限的表述是否诚实准确

**产出**：`discussion.md`

---

## 检查点 10：全文引用核查

**调用**：`literature-verifier`

**操作**：
- 扫描所有已生成文件中的参考文献和文内引用
- 对每条引用进行真实性核查
- 生成核查报告：✅ 已核实 / ⚠️ 存疑（需研究者自行确认）/ ❌ 无法确认

**用户确认**：
- 审阅核查报告
- 对存疑引用做出处理决定（删除/替换/保留并标注核实责任）

**产出**：引用核查报告

---

## 检查点 11：完稿汇总

**操作**（无需调用外部 skill，由工作流直接执行）：

汇总所有已生成文件，输出完稿清单：

```

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

已生成文件：
📄 literature_review.md      文献综述
📄 framework_[主题].md       理论框架建构文档
📄 framework_section_[A/B/C].md  理论框架章节
📄 introduction.md           引言
📄 methods.md                研究方法
📄 coding_[被访者].md × N    编码文件（N份）
```

## 流程控制规则

**随时可用的指令**：
- **"继续"**：进入下一检查点
- **"重做"**：重新执行当前检查点（保留之前产出作为参考）
- **"跳过"**：跳过下一个检查点（适用于已完成的环节）
- **"暂停"**：结束本次对话，下次从当前位置继续（告知用户：重新启动工作流时说明已完成至第N检查点）
- **"查看进度"**：显示当前已完成的检查点和待完成的检查点

**信息传递原则**：
- 理论定位（A/B/C）从检查点 3 确认后，在检查点 7、8、9 中自动沿用，无需重复询问
- 研究问题、目标期刊类型等基本信息全程共用
- 各检查点产出的文件路径统一记录，供后续检查点直接调用

**注意**：本 skill 是协调器，不做分析和写作工作。
各检查点的实际工作由对应的专项 skill 完成。
如专项 skill 需要额外信息，会在检查点内向你询问。
