## 模式1：按核心概念分类结构

**适用场景**：研究涉及 3-5 个核心概念/变量，需逐一梳理各概念的文献脉络，最后聚焦概念间关系。

```
第二章 文献综述
  2.1 核心概念界定与辨析
    2.1.1 概念 A 的内涵与外延
    2.1.2 概念 B 的内涵与外延
    2.1.3 概念 C 的内涵与外延
    2.1.4 核心概念间的关系辨析
  2.2 关于概念 A 的研究综述
    2.2.1 概念 A 的理论基础与发展脉络
    2.2.2 概念 A 的测量与操作化
    2.2.3 概念 A 的前因与后果研究
  2.3 关于概念 B 的研究综述
    2.3.1 概念 B 的理论基础与发展脉络
    2.3.2 概念 B 的测量与操作化
    2.3.3 概念 B 的前因与后果研究
  2.4 关于概念 C 的研究综述
    （结构类似 2.2/2.3）
  2.5 概念 A 与概念 B/C 的关系研究
    2.5.1 A→B 的直接效应研究
    2.5.2 A→C 的直接效应研究
    2.5.3 中介与调节机制研究
  2.6 研究述评与空白识别
  2.7 本章小结
```

**优点**：逻辑清晰，各概念独立成节便于深入；适合定量研究。
**注意**：避免各概念模块内容割裂，需在"关系研究"模块实现概念整合。

## 模式2：按理论流派分类结构

**适用场景**：研究议题有多个竞争性理论解释，需梳理各理论流派的发展脉络与论争。

```
第二章 文献综述
  2.1 核心概念界定与辨析
  2.2 理论流派 A 的文献综述
    2.2.1 理论起源与核心主张
    2.2.2 主要研究成果与实证发现
    2.2.3 理论局限与批评
  2.3 理论流派 B 的文献综述
    （结构类似 2.2）
  2.4 理论流派 C 的文献综述
    （结构类似 2.2）
  2.5 理论流派间的对话与整合
    2.5.1 各流派的共识与分歧
    2.5.2 理论整合的可能路径
  2.6 研究述评与空白识别
  2.7 本章小结
```

**优点**：理论脉络清晰，适合理论贡献导向的博士论文。
**注意**：需在 2.5 实现理论间的对话，避免流派孤立呈现。

## 模式3：按研究方法分类结构

**适用场景**：研究议题的定量研究与质性研究各有发现，方法选择本身是研究贡献之一。

```
第二章 文献综述
  2.1 核心概念界定与辨析
  2.2 定量研究视角下的文献综述
    2.2.1 问卷调查类研究
    2.2.2 实验研究
    2.2.3 二手数据分析研究
  2.3 质性研究视角下的文献综述
    2.3.1 案例研究
    2.3.2 扎根理论研究
    2.3.3 民族志与叙事研究
  2.4 混合方法研究综述
  2.5 方法论反思与比较
  2.6 研究述评与空白识别
  2.7 本章小结
```

**优点**：凸显方法论意识，适合方法论创新的博士论文。
**注意**：避免陷入纯方法描述，需始终围绕研究主题。

## 模式4：按时间演进分类结构

**适用场景**：研究议题经历了明显的范式转换或阶段性发展。

```
第二章 文献综述
  2.1 核心概念界定与辨析
  2.2 萌芽期（[起始年]-[年份]）：[主题描述]
    2.2.1 时代背景与问题意识
    2.2.2 早期代表性研究
  2.3 发展期（[年份]-[年份]）：[主题描述]
    2.3.1 理论框架的形成
    2.3.2 实证研究的拓展
  2.4 成熟/转型期（[年份]-至今）：[主题描述]
    2.4.1 新范式的确立
    2.4.2 前沿议题与新兴方向
  2.5 文献演进的总体脉络与趋势
  2.6 研究述评与空白识别
  2.7 本章小结
```

**优点**：脉络感强，便于呈现学术发展史。
**注意**：避免简单按年份罗列，每个时期需提炼核心主题和范式特征。

## 模式5：混合分类结构

**适用场景**：研究议题复杂，单一分类标准无法覆盖。最常见的组合：概念分类 + 理论分类。

```
第二章 文献综述
  2.1 核心概念界定与辨析
    2.1.1 概念 A 的界定
    2.1.2 概念 B 的界定
    2.1.3 概念辨析与关系
  2.2 概念 A 的研究综述（按概念分类）
    2.2.1 概念 A 的理论发展
    2.2.2 概念 A 的实证研究
  2.3 概念 B 的研究综述（按概念分类）
    （结构类似 2.2）
  2.4 [研究议题] 的理论视角综述（按理论分类）
    2.4.1 理论视角 X 的解释
    2.4.2 理论视角 Y 的解释
    2.4.3 理论视角间的比较与整合
  2.5 概念 A 与概念 B 的关系研究
  2.6 研究述评与空白识别
  2.7 本章小结
```

**优点**：灵活性高，兼顾深度与广度。
**注意**：分类标准的切换需有明确逻辑说明，避免结构混乱。

## 模式6：按研究层次分类结构

**适用场景**：研究议题涉及多层次分析（个体-团队-组织-制度等）。

```
第二章 文献综述
  2.1 核心概念界定与辨析
  2.2 微观层次（个体/心理层面）的研究综述
    2.2.1 个体行为与动机研究
    2.2.2 心理认知与态度研究
  2.3 中观层次（团队/组织层面）的研究综述
    2.3.1 团队过程与绩效研究
    2.3.2 组织结构与文化研究
  2.4 宏观层次（制度/社会层面）的研究综述
    2.4.1 制度环境与政策研究
    2.4.2 社会网络与场域研究
  2.5 跨层次互动研究
  2.6 研究述评与空白识别
  2.7 本章小结
```

**优点**：层次分明，适合跨层次研究设计。
**注意**：需在 2.5 打通各层次间的逻辑关联。

## 结构选择决策指南

| 研究特征 | 推荐结构 |
|---------|---------|
| 核心概念 3-5 个，定量研究为主 | 模式1（概念分类） |
| 存在 2-3 个竞争性理论解释 | 模式2（理论流派） |
| 方法论创新是核心贡献 | 模式3（研究方法） |
| 研究议题有明显的阶段性发展 | 模式4（时间演进） |
| 概念多、理论多，单一标准不够 | 模式5（混合分类） |
| 涉及多层次分析（个体-组织-制度） | 模式6（研究层次） |
| 不确定 | 默认模式1或模式5 |

**选择原则**：
1. 分类标准必须与研究主问题直接相关
2. 每个模块必须有独立的文献支撑（≥15 条）
3. 模块间必须有逻辑衔接，避免"信息孤岛"
4. 总模块数控制在 4-7 个（含概念界定、述评与小结）
