## 模板A：核心概念界定与辨析模块

**适用范围**：P4 阶段的第一个主题模块（通常为"2.1 核心概念界定与辨析"）。
**目标字数**：1,500 - 2,500 字。

### 写作结构与逻辑

**开篇段（150-200字）**：
点明本节任务——对本研究涉及的核心概念进行学术界定，明确概念的内涵、外延及相互关系，为后续文献梳理奠定概念基础。

**概念A界定（400-600字）**：
```
段落1：概念的词源/学术起源
  → 该概念最早由[学者](年份)在[情境]下提出，原始定义为"..."（Author, Year）。
  → 此后，不同学者从不同视角进行了拓展...

段落2：主要定义的比较与演进
  → 从[视角1]出发，[学者群]将其定义为"..."（Author1, Year; Author2, Year）。
  → 从[视角2]出发，[学者群]则强调"..."（Author3, Year; Author4, Year）。
  → 综合来看，上述定义的共同核心在于...，差异在于...。

段落3：本文采用的定义及理由
  → 基于本研究的[具体情境/研究问题]，本文采用[学者](年份)的定义，即"..."。
  → 选择该定义的理由在于：第一，...；第二，...。
```

**概念B界定（400-600字）**：结构同上。

**概念C界定（400-600字）**：结构同上。

**概念辨析段（300-500字）**：
```
段落：相近概念的辨析
  → 在既有文献中，概念A常与[相近概念X][相近概念Y]混用（Author, Year）。
  → 三者的核心区别在于：[列出2-3个关键区分维度]。
  → 本文将概念A与[相近概念]做出如下区分...
```

**收束段（100-150字）**：
概括本节界定结论，过渡至下一节。例如："在明确了X、Y、Z三个核心概念的内涵之后，下一节将围绕[主题A]展开系统的文献梳理。"

## 模板B：理论脉络与发展综述模块

**适用范围**：梳理某一核心概念或理论流派的完整研究发展脉络。
**目标字数**：2,500 - 4,000 字。

### 写作结构与逻辑

**开篇段（200-300字）**：
点明本节综述对象与任务，说明与研究主问题的关联，概括本节的组织逻辑。

**第一层：理论起源与奠基研究（600-800字 长段落）**：
```
该领域的研究可追溯至[学者](年份)的开创性工作。在[时代背景]下，
[学者]首次提出了[核心概念/理论]，其核心主张为...（Author, Year）。
这一开创性贡献奠定了该领域的基本分析框架，具体表现在三个方面：
第一，...（Author, Year; Author, Year）；
第二，...（Author, Year）；
第三，...（Author, Year; Author, Year）。
此后，[后续学者群]在此基础上进行了重要拓展。[学者A](年份)将
[核心概念]从[原始情境]延伸至[新情境]，发现...（Author, Year）。
与此同时，[学者B](年份)从[不同视角]对[核心概念]进行了重新解读，
提出了[新框架/新维度]（Author, Year）。这些早期研究共同塑造了
该领域的基本研究范式，即...。
```

**第二层：发展期研究与理论分化（600-800字 长段落）**：
```
进入[时间段]，该领域经历了显著的理论分化与研究深化。一方面，
[学术共同体A]从[视角A]出发，形成了以[学者](年份)为代表的
[研究传统/学派]，该学派强调...（Author, Year; Author, Year; Author, Year）。
另一方面，[学术共同体B]从[视角B]切入，提出了[竞争性解释/互补性框架]
（Author, Year）。两个研究传统之间的核心论争在于：...。

从实证层面来看，这一时期的研究在以下方面取得了重要进展：
首先，在[研究主题1]方面，多项研究一致表明...
（Author1, Year; Author2, Year; Author3, Year）。
其次，在[研究主题2]方面，研究发现呈现出一定的分歧——
[一组研究]报告了...（Author, Year），而[另一组研究]则发现...
（Author, Year），这种不一致可能源于[方法/样本/情境差异]。
```

**第三层：前沿进展与新兴方向（600-800字 长段落）**：
```
近年来（[近5年]），该领域呈现出若干新趋势。第一，...
第二，...第三，...。
这些新兴方向的共同特征在于...，反映了学界对[更深层问题]的持续关注。
```

**批判性评价段（300-400字）**：
```
然而，上述研究仍存在以下不足：
在理论层面，...（Author, Year 曾明确指出这一局限）。
在方法层面，...。
在情境覆盖方面，...。
这些不足为后续研究提供了明确方向，也构成本文[相关章节]的重要切入点。
```

**收束过渡段（100-150字）**：
概括本节核心发现，逻辑过渡至下一节。

## 模板C：实证研究评述模块

**适用范围**：对某一研究主题的实证发现进行系统性综合评价。
**目标字数**：2,500 - 4,000 字。

### 写作结构与逻辑

**开篇段（200-300字）**：
点明本节聚焦的实证研究主题，说明选择该主题的理由及组织逻辑。

**共识性发现综合（600-800字 长段落）**：
```
在[研究主题]方面，已有研究积累了丰富的实证证据。
总体而言，学界对以下结论已形成较为广泛的共识：
第一，[结论1]。大量研究通过[方法类型]证实了[具体发现]
（Author1, Year; Author2, Year; Author3, Year; ...多源引用）。
例如，[代表性研究1]以[样本]为对象，采用[方法]发现...（Author, Year）；
[代表性研究2]在[不同情境]下验证了类似结论（Author, Year）。
第二，[结论2]。来自[不同方法/情境]的汇聚证据表明...
（Author, Year; Author, Year; Author, Year）。
值得注意的是，[元分析研究](年份)基于[N]项研究的系统整合，
报告了[具体效应量/结论]（Author, Year），为上述共识提供了
更为稳健的统计支撑。
```

**分歧性发现与边界条件（600-800字 长段落）**：
```
然而，并非所有实证发现都指向一致结论。在[争议领域]，
研究结果呈现出显著分歧。一方面，...（Author, Year; Author, Year）
报告了[发现A]。另一方面，...（Author, Year; Author, Year）
则发现[相反/不同的发现B]。

这种不一致可归因于以下边界条件：
（1）情境调节效应：在[情境1]下，[关系]更为显著（Author, Year）；
   而在[情境2]下，该效应减弱甚至逆转（Author, Year）。
（2）方法差异：采用[方法A]的研究倾向于发现...，
   而采用[方法B]的研究更多报告...（Author, Year 对此进行了讨论）。
（3）样本特征：[样本类型]的差异可能是导致结果分歧的重要原因
   （Author, Year; Author, Year）。
```

**中介/调节机制研究（500-700字）**：
```
在机制解释方面，学者们主要从以下路径探讨了[核心关系]的作用机制：
（1）[中介路径1]：...（Author, Year; Author, Year）认为...
（2）[中介路径2]：...
（3）[调节条件]：...

然而，现有机制研究仍不够深入，主要表现在：...。
```

**研究方法评价段（300-400字）**：
```
从方法论角度审视上述研究，可以发现以下特征与不足：
在研究设计方面，[占比]采用了[设计类型]，[比例]使用了[另一设计类型]...
在数据来源方面，...
在测量工具方面，...
这些方法特征在一定程度上限制了现有结论的[因果推断力/外部效度/...]。
```

**收束过渡段（100-150字）**：
总结本节核心发现与不足，过渡至下一节。

## 模板D：变量关系与机制研究模块

**适用范围**：专门综述两个或多个核心变量之间关系的已有研究。
**目标字数**：2,500 - 3,500 字。

### 写作结构与逻辑

**开篇段（200-300字）**：
说明本节聚焦 A→B 的关系研究，点明此关系对本研究的重要性。

**直接效应研究综合（600-800字 长段落）**：
```
关于[变量A]对[变量B]的直接影响，现有研究提供了[丰富的/有限的/
矛盾的]实证证据。早期研究中，[学者](年份)首次实证检验了二者关系，
发现...（Author, Year）。此后，[多项/大量]研究在不同样本和情境下
对这一关系进行了验证与拓展。

总体来看，[主流发现/多数研究]支持A与B之间存在[正向/负向/倒U型]
关系（Author1, Year; Author2, Year; Author3, Year; ...）。
[元分析/系统综述](若有)报告的平均效应量为[r/d值]（Author, Year），
表明该效应具有[统计/实际]显著性。

然而，也有研究报告了[不一致的/非显著的]结果（Author, Year; Author, Year），
这些发现暗示该关系可能受到[情境因素]的调节...
```

**中介机制研究（500-700字）**：
```
为解释[A→B]关系的内在机制，学者们提出并检验了多条中介路径：
第一，[中介变量M1]路径。[学者群]基于[理论]，认为A通过影响M1
进而作用于B（Author, Year; Author, Year）。实证检验方面，...

第二，[中介变量M2]路径。不同于M1路径的解释视角，[学者群]
从[另一理论]出发，提出了A→M2→B的传导机制（Author, Year）...

上述中介路径的比较表明，...。但多数研究仅检验了单一中介路径，
缺乏对多重中介的整合分析...
```

**调节效应研究（500-700字）**：
```
在A→B关系的边界条件方面，现有研究识别了若干重要调节变量：
（1）[调节变量W1]：...
（2）[调节变量W2]：...
（3）[调节变量W3]：...

这些调节效应的发现具有重要的理论含义——它们表明A→B关系并非
普遍适用，而是受到[层面]因素的显著制约。然而，现有调节效应
研究存在以下不足：...
```

**收束过渡段（100-200字）**：
概括 A→B 关系研究的总体图景，指出关键空白，过渡至下一节。

## 模板E：研究述评与空白识别模块

**适用范围**：P5 阶段，对全章文献综述的系统性总结与批判。
**目标字数**：2,000 - 3,000 字。

### 写作结构与逻辑

**开篇段（150-200字）**：
"通过上述对[研究主题]相关文献的系统梳理，可以看到该领域在理论建构、实证检验和方法创新等方面取得了丰硕成果，但也存在若干尚待解决的问题。本节将从理论、方法、内容和情境四个维度对已有研究进行系统性述评，并在此基础上识别研究空白，明确本研究的切入方向。"

**已有研究贡献总结（400-500字）**：
```
总体而言，已有研究在以下方面做出了重要贡献：
第一，在理论层面，...奠定了[领域]的基本理论框架
（Author, Year; Author, Year）。
第二，在实证层面，...积累了丰富的实证证据
（Author, Year; Author, Year; Author, Year）。
第三，在方法层面，...推动了研究方法的不断革新（Author, Year）。
这些成果为后续研究提供了坚实基础。
```

**系统性不足评述（800-1000字 长段落为主）**：
```
然而，将上述研究置于[本研究主问题]的视角下审视，
仍然存在以下系统性不足：

其一，理论视角的局限。现有研究主要依赖[单一/有限的]理论视角
（如[理论名]），对[其他理论视角]的运用相对不足（Author, Year
曾指出这一缺陷）。具体而言，...这使得对[现象]的理论解释
缺乏[多元性/深度/整合性]。

其二，研究方法的制约。在已梳理的文献中，[占比]采用了[方法类型]，
而[其他方法类型]的应用相对匮乏。这导致：（1）...；
（2）...；（3）...。[学者](年份)亦呼吁"引用该学者的原话或概括"
（Author, Year, p.XX）。

其三，研究情境的偏狭。现有研究的样本主要集中在[地域/行业/组织类型]，
对[本研究关注的情境]关注不足。考虑到[情境差异的重要性论证]，
这一覆盖不足限制了现有结论的推广性。

其四，研究内容的空白。在[核心关系/机制/现象]方面，
现有研究尚未充分探讨以下议题：...。
```

**研究空白明确列举（600-800字）**：
```
基于上述述评，本文识别出以下具体研究空白：

Gap 1：[具体空白描述]。尽管已有研究关注了[已知方面]
（Author, Year; Author, Year），但对于[具体未知方面]，
现有文献尚缺乏系统性探讨。这一空白的存在使得...

Gap 2：[具体空白描述]。在[具体领域]，现有研究主要采用
[已有方法/视角]（Author, Year），尚未运用[新方法/新视角]
来揭示[深层机制]。正如[学者](年份)所指出的，"..."
（Author, Year, p.XX）。

Gap 3：[具体空白描述]。关于[变量A]与[变量B]在[特定情境]
下的关系，目前仅有[有限的/尚无]实证研究
（Author, Year 是为数不多的尝试）。

[Gap 4/5 视需要而定]
```

**本研究切入逻辑（400-500字）**：
```
上述研究空白为本研究提供了明确的切入方向。具体而言，
本研究拟从以下方面回应上述空白：
针对 Gap 1，本研究将...；
针对 Gap 2，本研究拟采用...；
针对 Gap 3，本研究聚焦[特定情境]，...。

通过上述努力，本研究期望在[理论/方法/实践]层面做出如下贡献：
第一，...；第二，...；第三，...。
接下来的第三章将在本章文献综述与研究空白识别的基础上，
构建本研究的[理论框架/研究设计]。
```
